# Security policy — DataVista Studio

This repository is the **public portfolio and project directory** for DataVista Studio. It is not a deployment repository, an authorization to test production services, or an offer to disclose commercial source code.

## Reporting a concern

For suspected security vulnerabilities, exposed credentials, privacy incidents, or other non-public findings, **do not post technical details in a public GitHub issue**.

Use our [official contact page](https://datavista.studio/contact) to request a private reporting channel. Please identify the affected product and provide a brief, non-sensitive description. Do not send passwords, authentication tokens, personal records, raw logs or customer content in an initial message.

An acknowledgement or resolution time is **not promised** by this public document.

## Scope and authorization

Each DataVista product has its own access restrictions, development environment, release approvals and legal considerations. Public product pages and illustrations are not authorization to probe, exploit, scan or access protected systems.

- No access to private application code or production infrastructure is granted by this repository.
- No changes to payment, account, authentication, media, or customer-data systems are accepted through portfolio content alone.
- A successful isolated test, a draft pull request, or a public screenshot does **not** constitute a production release approval.
- Do not open publicly accessible issues containing secrets, personal information, private URLs, exploit details or unreleased operational plans.

For corrections to **public portfolio wording, artwork, or broken public links only**, a non-sensitive GitHub issue may be appropriate.

## Intellectual property

Descriptions and editorial illustrations here are for presentation. No rights to redistribute third-party news, media, books, datasets, customer information, proprietary software or brand assets are implied.
