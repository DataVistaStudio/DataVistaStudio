# Contributing to DataVista Studio's public portfolio

Thank you for helping keep this public presentation accurate. This repository is **not an open-source release of DataVista commercial products**.

## Appropriate public contributions

- Corrections to product names, links, accessibility text and language.
- Reports of broken **public** URLs or mismatched portfolio illustrations.
- Clear feedback on a public project description or launch/preview status.

Use the [Portfolio correction issue template](https://github.com/DataVistaStudio/DataVistaStudio/issues/new/choose). Include only publicly observable information. A small documentation-only pull request can be considered where appropriate; opening an issue does not authorize changes to private code or infrastructure.

## What not to publish

Never include credentials, authentication tokens, personal or customer data, private feed links, confidential documents, screenshots of operator/admin areas, security exploit steps, or third-party copyrighted materials without permission.

For a possible vulnerability or confidential finding, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Review and rights

DataVista may review, defer or decline unsolicited changes. Approved branding, imagery and descriptions do not establish a general license to third-party content, private implementations or commercial data.
